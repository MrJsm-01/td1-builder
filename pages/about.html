About

{{ site.meta.title }} is an unofficial fanmade website for creating and sharing The Division builds.

This is not a tool for theorycrafting, the builder does not calculate any gameplay stats. It is mainly a way to visualize your build, making it easy to share.

Technical Info

This is a client-side app, with only static content. Because of that, there are no server-side features such as authentication, player profiles, voting or discussion.

The shareable link is unfortunately (very) long because it stores your selections, then compresses, encodes, and decodes it entirely in the browser so your build can be reconstructed later.
